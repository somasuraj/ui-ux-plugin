Same job, same model, same prompt: without the skill vs with it

Two jobs were each given to two fresh agents that had never seen this project. The only difference between each pair: one was told to use only its own knowledge, the other was told to use the ui-ux skill. Screenshots below are scrollable; "open live page" opens the real HTML.

  • Job 1, refactor: "Improve the UI and UX of Ledgerly (a deliberately broken 3-page invoicing app). Make it look professional and easy to use."
  • Job 2, create: "Build a Team tasks screen plus a New task form for a task tracker called Tasklane, from an empty folder."
  • The two skill runs were interrupted by a usage limit after writing their files and were resumed to finish the skill's verify step. The no-skill runs had already finished.
  • Numbers come from the same scripts run on every version (scan.py, notes/fidelity.py). One run each: treat small differences as noise.

What this shows, honestly

Both versions look professional. A strong model already designs well on its own. On the from-scratch job the two results are close, and the no-skill one is arguably richer (summary cards, search, relative due dates). If you only judge by a glance, the skill does not buy a dramatic visual difference.

The real difference is in redesigning an existing app. Without the skill the agent built a nicer app than the one it was given: it deleted the product's real navigation, invented six sections, and quietly changed invoice data. With the skill it improved the same app: real nav kept and flagged, data untouched, the hidden fee surfaced, and a list of questions for the owner.

With the skill the agent checks its own work. Neither no-skill run ever rendered its pages. Both skill runs took screenshots at desktop and phone width, looked at them, and fixed layout and contrast bugs before finishing. The cleaner code-health numbers follow from that.

The skill is not perfectly obeyed. It says not to add placeholder features or unsourced claims; the skill run still added a "New invoice" stub and "No card needed", though it reported both. One run per cell; small number differences are noise.

Notes written by each agent are in notes/; raw scanner output in notes/scan-*.txt.
