# Ledgerly fixture - UI/UX audit (T5 baseline, no skill)

Scope: `fixture/index.html`, `fixture/invoices.html`, `fixture/signup.html`, `fixture/styles.css`. Read-only static review (no browser). Contrast ratios are computed by hand from the hex values using the WCAG relative-luminance formula; treat them as accurate to about +/-0.1.

Severity: **Critical** = blocks a task, excludes a user group, or destroys trust / risks data loss. **Major** = significantly hurts comprehension, conversion or efficiency. **Minor** = polish / consistency.

Totals: **Critical 11, Major 42, Minor 19 (72 findings)**.

---
